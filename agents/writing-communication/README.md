# Writing and Communication Agents

> Agents for drafting, editing, summarising and turning rough notes into something you can send.

[← Back to the main collection](../../README.md)

---

- [**AI Text Humanizer**](ai-text-humanizer.md): Paste any text and the agent strips out the tells that mark it as AI-generated
- [**Business Case Builder**](business-case-builder.md): Describe a proposed initiative in any format, rough notes, a bullet list, a paragraph of context...
- [**Comms Clarity Coach**](comms-clarity-coach.md): Paste any business communication, an internal announcement, policy update, project update email, presentation speaker notes...
- [**Email Tone Coach**](email-tone-coach.md): Paste an email draft and specify the tone you need
- [**Executive Summary Maker**](executive-summary-maker.md): Paste any document, report extract, or dense briefing note and the agent produces a five-section executive summary
- [**Language Translator**](language-translator.md): Paste any text and specify the target language
- [**Meeting Minutes Writer**](meeting-minutes-writer.md): Paste raw meeting notes, a voice-to-text transcript, or rough bullet points and the agent formats them into clean, structured meeting minutes
- [**Report Narrative Builder**](report-narrative-builder.md): Paste data tables, KPI summaries, bullet points of findings, or a collection of raw results and the agent converts them into narrative prose...
